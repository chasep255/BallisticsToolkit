Overview

Generate printable competition targets at exact 1:1 physical scale. Targets larger than the paper are clipped at the page edge. The tool supports tiling multiple targets per page for smaller targets.

Target Presets

Select from 14 standard competition target configurations covering Short Range (SR), Mid Range (MR), Long Range (LR), and F-Class disciplines. Ring diameters match official specifications.

Select "Custom" to define your own ring sizes from scratch, or modify any preset after loading it.

Ring Editor

Each row defines a scoring ring with its diameter (in inches), fill color, and line (stroke) color. Rings are drawn outermost to innermost, with each ring painting over the previous one.

Standard coloring: outer rings (5-6) are white fill with black lines; inner rings (7-10, X) are black fill with white lines.

Print Settings

Paper Size: Standard paper sizes or custom dimensions. All ring dimensions are printed at exact physical size (1:1 scale).

Cols / Rows: Number of columns and rows to tile on one page. Set both to 1 for a single full-page target; use e.g. 2 cols × 3 rows for six targets per page. Each target is centered and clipped within its cell.

Margins: Page margins in inches. Applies to all edges.

Show Ring Labels: Display ring numbers at the left and right of each ring boundary.

Show Target Info: Display target name and description below each target.

Printing Tips

When printing, ensure your print dialog is set to "Actual Size" or "100%" scale (not "Fit to Page"). This ensures rings print at their exact physical dimensions. Measure a printed ring with a ruler or calipers to verify accuracy.
